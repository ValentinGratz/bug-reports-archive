# Jeu Head & Shoulders : redirection vers l'accueil après le décompte

## Informations

* Application : Carrefour
* Plateforme : Android (Huawei)
* Appareil : P20 lite
* Version Android : Android 9
* Version de l'application : 23.3.0
* Date : 2026-06-23
* Statut : Ouvert

---

## Description

Lors du lancement du nouveau jeu Head & Shoulders dans l'application Carrefour, un décompte s'affiche.

Le chiffre « 3 » apparaît puis le jeu disparaît immédiatement et l'application redirige automatiquement vers la page d'accueil.

Le problème a été reproduit plusieurs fois.

## Étapes pour reproduire

1. Ouvrir l'application Carrefour
2. Ouvrir le jeu Head & Shoulders
3. Lancer le jeu
4. Attendre l'apparition du décompte
5. Observer le retour automatique vers l'accueil

## Résultat attendu

Le jeu doit démarrer normalement après le décompte.

## Résultat obtenu

Le jeu se ferme immédiatement après le début du décompte et l'utilisateur est renvoyé vers l'écran d'accueil de l'application.
