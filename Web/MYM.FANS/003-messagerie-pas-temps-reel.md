# Bug 003 - Les nouveaux messages ne s'affichent pas en temps réel

## Plateforme
MYM (mym.fans)

## Catégorie
Messagerie / Temps réel / Expérience utilisateur

## Description du problème

Les nouveaux messages reçus dans la messagerie MYM ne semblent pas apparaître automatiquement.

Contrairement à certaines messageries modernes comme Messenger, les nouveaux messages nécessitent parfois une actualisation manuelle de la page.

## Étapes pour reproduire

1. Ouvrir une conversation MYM.
2. Laisser la page ouverte.
3. Recevoir un nouveau message d'un créateur.
4. Observer l'affichage de la conversation.

## Résultat attendu

Le nouveau message devrait apparaître automatiquement sans action nécessaire de l'utilisateur.

## Résultat constaté

Le message n'apparaît pas immédiatement.

L'utilisateur doit :
- actualiser la page ;
- ou recharger la conversation ;

pour voir apparaître le nouveau contenu.

## Impact utilisateur

Cela peut entraîner :

- un retard dans la lecture des messages ;
- une impression que la plateforme n'est pas active ;
- une expérience moins fluide lors des échanges entre créateurs et fans.

## Comparaison

Des services comme Messenger utilisent une mise à jour en temps réel permettant l'affichage immédiat des nouveaux messages.

## Fréquence

Observé régulièrement depuis plusieurs années.

## Informations complémentaires

Le problème semble indépendant du navigateur utilisé et pourrait être lié au fonctionnement de la messagerie côté plateforme.
