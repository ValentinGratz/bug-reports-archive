## 📌 About

This repository is a personal archive of bug reports collected across different platforms, apps, and websites.

It serves as:
- A structured bug tracking journal
- A QA-style documentation practice
- A portfolio of real-world issues encountered in production systems

---

## 🧩 Structure

Bug reports are organized by platform:

- 📱 Facebook
- 📸 Instagram
- 🤖 Android
- 🍏 iOS
- 🌐 Web
- 🧪 Other systems

Each bug is stored as a markdown file following a consistent template.

---

## 📝 Bug Report Format

All reports follow a standardized structure:

- Bug title
- Reproduction steps
- Symptoms (UI behavior)
- Console / network logs
- Tests performed
- First appearance
- Impact assessment
- Optional IDs / URLs

See `/Templates/bug-template.md` for full format.
