## Résumé

Cet article analyse plusieurs problèmes persistants sur Facebook Web en 2026, malgré les évolutions produit et l’intégration croissante de l’IA dans les systèmes Meta.

Il met en avant une réalité souvent rapportée par les utilisateurs et développeurs :  
le web Facebook reste instable sur certains comportements critiques.

---

## Points abordés

### 1. Bugs persistants sur l’interface web
Certains comportements UI restent incohérents ou cassés sur navigateur, même après plusieurs itérations produit.

### 2. Incohérences entre mobile et web
Des fonctionnalités disponibles sur mobile ne fonctionnent pas correctement sur la version web.

### 3. Dégradation de certaines expériences utilisateurs
Certaines actions deviennent instables ou imprévisibles selon les contextes (navigation, cache, état session).
