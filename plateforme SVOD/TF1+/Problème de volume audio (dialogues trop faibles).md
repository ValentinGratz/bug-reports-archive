# TF1+ — Problème de volume audio (dialogues trop faibles)

## Plateforme
TF1+ (replay / streaming)

## Type de problème
Audio — niveau sonore / normalisation du volume

## Description

Sur plusieurs contenus récents disponibles sur TF1+, le niveau sonore global est anormalement bas, avec un problème particulièrement marqué sur les dialogues.

Les voix sont difficilement audibles sans augmenter fortement le volume de la télévision, alors que d’autres programmes sur la même plateforme sont correctement équilibrés.

## Exemple concret

- Programme concerné : *Zodiaque (2026)* (replay TF1+)
- Symptôme : dialogues très faibles, volume global trop bas
- Volume TV nécessaire : environ 60–70 pour un niveau d’écoute correct

Comparaison :
- Autre programme TF1+ (ex : ITC) : volume normal autour de 20 sur la même installation

## Comportement attendu

Le niveau sonore des dialogues devrait être :
- clair et intelligible sans augmentation excessive du volume
- cohérent entre les différents programmes disponibles sur TF1+

## Comportement observé

- Dialogues trop faibles
- Forte disparité de volume entre les programmes
- Obligation d’augmenter fortement le volume sur certains contenus uniquement

## Hypothèse

Problème possible de :
- normalisation audio incohérente entre les contenus
- mixage audio non standardisé pour certains programmes récents
- absence ou mauvaise application de loudness normalization (type EBU R128)

## Impact utilisateur

- Expérience de visionnage dégradée
- Obligation de modifier constamment le volume selon les programmes
- Incohérence importante entre contenus d’une même plateforme

## Remarques

Le problème semble spécifique à certains contenus TF1+, car aucun problème similaire n’est constaté sur d’autres applications ou sources TV.
