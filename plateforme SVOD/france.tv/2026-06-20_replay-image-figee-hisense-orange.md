# Bug France.tv Replay - Image figée mais son continue

**Statut :** Signalé le 20/06/2026  
**Produit concerné :** France.tv Replay via Box Orange  
**Sévérité :** Majeure - empêche le visionnage complet  

## Description

Lors du visionnage d’un programme en replay sur France.tv, l’image se fige complètement alors que le son continue normalement. Un retour arrière de quelques secondes est nécessaire pour débloquer l’image.

Le bug survient aussi bien en milieu qu’en fin de programme, avec une fréquence plus élevée sur la fin des émissions.

## Environnement

| Élément | Détail |
| --- | --- |
| TV | Hisense |
| Box TV | Orange |
| Connexion | Fibre |
| Application | France.tv via interface Box Orange |
| Date du dernier cas | 20/06/2026 à 14h05 |

## Étapes pour reproduire

1. Lancer un replay France.tv depuis la box Orange
2. Regarder le programme normalement
3. À un moment aléatoire, souvent vers la fin, l’image se fige
4. Le son continue
5. Action de contournement : faire "retour arrière" 10s pour récupérer l’image

## Programme témoin du 20/06/2026
- **Émission :** Laissez-vous guider
- **Heure du bug :** ~14h05

Le problème n’est pas spécifique à ce programme. Constaté sur plusieurs replays différents.

## Impact utilisateur
Obligation de manipuler la télécommande plusieurs fois par programme. Expérience très dégradée, surtout pour les conclusions d’émissions.

## Signalement
Rapport envoyé à France Télévisions le 20/06/2026 via formulaire "France TV & Vous".  
Contact possible aussi au 30 60.

## Contournement temporaire
Mettre la vidéo sur pause, retour en arrière et ça refonctionne.
